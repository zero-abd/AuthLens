# Test Videos

## Instructions

This folder is for storing test video files used during development and testing of AuthLens.

### Setup

Please upload **two one-minute videos** (MP4 format) in this folder for testing purposes:

1. **test1.mp4**: A sample video for authentication testing
2. **test2.mp4**: A second video for comparison and validation testing

### Requirements

- **Format**: MP4
- **Duration**: Approximately 1 minute each
- **Purpose**: Used for testing video authentication and validation features

### Note

Video files (*.mp4) in this folder are excluded from version control via .gitignore to keep the repository size manageable.
